# Retired models

Made once and taken out of the game. They are kept here, outside
`art/static/source/`, so the build ignores them; the Meshy tool lists them
under `retired` in `art/meshy/requests.json`, so it never makes them again.

| Model | Why |
|---|---|
| `nodes/oak_c.glb` | Meshy batch 1: asked for "very wide, low spreading branches", it fits a lone oak, not a forest. Fitted to the oak's 5 m height its crown is 6.5 m wide and buries the trees around it. It also stands on a grass mound (`cut_plate = { c = 0.08 }` removes it). |
